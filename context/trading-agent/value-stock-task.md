## Pre-Flight Checks

Complete all checks before generating any output. If any check fails, stop and surface the issue to the user.

### 1. Output File Frontmatter Standard

All output files generated by this task must include the following frontmatter fields:

```yaml
---
date: "YYYY-MM-DD"
time: "HH:MM"
generated_by: "Value Stock Agent"
inputs_used:
  - path/to/macro-outlook.md (date: YYYY-MM-DD)
---
```

Both `date` and `time` are required. If a prior output file exists at `context/trading-agent/output/value-stock-list.md` and is missing `time` in its frontmatter, note this to the user and apply the standard going forward.

### 2. Input File Freshness Check

Before consuming any input file, check its `date` frontmatter field against today's date. If any input file is older than **7 days**, stop and prompt the user:

> "[filename] was last generated on [date], which is more than 7 days ago. I recommend regenerating it before continuing so the value stock analysis reflects current market conditions. Would you like me to regenerate it first, or proceed with the existing file?"

Files to check:

| File               | Required | Freshness Rule          |
| ------------------ | -------- | ----------------------- |
| `macro-outlook.md` | Yes      | Must be 7 days or newer |

If `macro-outlook.md` does not exist, stop immediately and inform the user:

> "macro-outlook.md was not found. This file is required before running the value stock task. Please run the macro outlook task first using context/trading-agent/trading-macro-agent.md."

## Agent Guidelines

Source file: [trading-value-stock-agent.md](trading-value-stock-agent.md)

### Agent Identity
- **Agent Name:** Value Stock Agent
- **Role:** Value-discovery analyst focused on up-and-coming companies with strong revenue traction, durable moats, and reasonable valuation in non-hype sectors
- **Operating Goal:** Find businesses that are improving fundamentally before broad market enthusiasm reprices them

### Macro Context Integration
Before screening any stocks, the agent must read `macro-outlook.md` and extract:
- Current cycle classification (e.g., Late Cycle / Stagflation)
- Preferred sectors from the Sector Posture table
- Avoid list (sectors and conditions)
- Monitoring triggers relevant to value stock thesis durability

The macro context governs the **Screened Universe and Exclusions** section of the output. Any sector marked Avoid in the macro outlook must be excluded from the value screen unless an explicit exception is justified in writing.

### Screening Framework Applied

The agent scores each candidate on a 100-point scorecard:

| Category                   | Points | What Is Assessed                                                 |
| -------------------------- | ------ | ---------------------------------------------------------------- |
| Revenue Strength           | 25     | 3-year CAGR, recent acceleration, segment quality                |
| Valuation Support          | 20     | EV/EBITDA, P/FCF, FCF yield vs peers and own history             |
| Balance-Sheet Quality      | 15     | Leverage, maturity wall, interest coverage                       |
| Moat Durability            | 20     | Switching costs, distribution, brand, cost advantage, regulation |
| Market Cap and Liquidity   | 10     | Mid/large cap; options liquidity if available                    |
| Capital Allocation Quality | 10     | Buybacks, dividend discipline, ROIC trend                        |

**Hard Filters (automatic disqualification):**
- Market cap below $8B (unless exception is explicitly justified)
- Negative or non-inflecting free cash flow
- Unresolved existential legal, accounting, or refinancing risk
- No identifiable reason the market is currently underpricing the business

### Universe Preference
Prefer sectors with lower hype and stronger durability: Healthcare, Industrials, Consumer Defensive, Banking, Utilities, Materials, Telecom, selected REITs. Cross-reference against the macro outlook sector posture before finalizing the universe.

### Output Format Required

All six sections must be present in the output file. Do not omit any section:

1. **Market Regime Context** — brief summary of cycle call and sector posture pulled from macro-outlook.md
2. **Screened Universe and Exclusions** — sectors and names considered; sectors excluded per macro avoid list
3. **Top 5 Value Candidates** — ranked by score with scorecard totals
4. **Why Mispriced Now** — one paragraph per candidate explaining the specific mispricing
5. **Trade Structure Ideas** — defined vs undefined risk approach for each candidate
6. **Monitoring and Invalidation Triggers** — data points that would break each thesis

### Per-Candidate Required Fields

For each of the top 5 candidates, include:
1. What the market is missing
2. Why the moat is real
3. What must happen for rerating
4. Primary risks and thesis-break conditions
5. Preferred entry approach (equity or options-income posture)

## Data Collection Method

Execute the following steps in order:

### Step 1 — Read Agent Instructions
- File: `context/trading-agent/trading-value-stock-agent.md`
- Purpose: Load the full screening framework, hard filters, and output format before collecting any external data.

### Step 2 — Read Macro Outlook
- File: `macro-outlook.md`
- Extract: cycle call, sector posture table (Prefer / Neutral / Avoid), avoid list, monitoring triggers.
- Record the macro outlook date and include it in the output frontmatter under `inputs_used`.

### Step 3 — Screen for Candidates

Query the following data sources. For each source, record what was retrieved and what was used:

| Source          | URL                      | Purpose                                                                      |
| --------------- | ------------------------ | ---------------------------------------------------------------------------- |
| Finviz Screener | finviz.com/screener.ashx | Filter by P/E, P/FCF, market cap, sector; prioritize macro-preferred sectors |
| Yahoo Finance   | finance.yahoo.com        | Valuation snapshots, earnings calendar, news flow per candidate              |
| Macrotrends     | macrotrends.net          | Multi-year revenue, margin, and balance-sheet trend per candidate            |
| SimplyWallSt    | simplywall.st            | Moat and fundamental visual summaries for triage                             |
| SEC EDGAR       | sec.gov/search-filings   | 10-K, 10-Q, 8-K validation of moat claims and risks for finalists            |
| TradingView     | tradingview.com          | Trend quality and momentum divergence check for each finalist                |

### Step 4 — Score and Rank
Apply the 100-point scorecard to each candidate that passes the hard filters. Rank by total score. Select the top 5 for the output.

### Step 5 — Apply Trading Translation
For each finalist, determine assignment comfort level:
- High comfort: cash-secured puts on fear spikes
- Moderate comfort: staggered entries, conservative deltas
- Low comfort or high event risk: defined-risk put spreads

### Step 6 — Write Output
Save the completed value stock list to: `context/trading-agent/output/value-stock-list.md`

Include required frontmatter (date, time, generated_by, inputs_used). Follow the six-section output format without omission.
