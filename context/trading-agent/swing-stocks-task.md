> "Generate a swing stock list of punished but fundamentally solid companies with credible turnaround paths and clear catalyst timelines."

Both `date` and `time` are required.

### 2. Input File Freshness Check

Before consuming any input file, check its `date` frontmatter field against today's date.

Files to check:

| File               | Required | Freshness Rule          | If Missing                                          |
| ------------------ | -------- | ----------------------- | --------------------------------------------------- |
| `macro-outlook.md` | Yes      | Must be 7 days or newer | Stop. Ask user to run the macro outlook task first. |

If `macro-outlook.md` is older than 7 days, stop and ask:

> "macro-outlook.md was last generated on [date], which is more than 7 days ago. The macro cycle call affects which sectors and drawdown types are valid swing candidates today. I recommend regenerating it first. Would you like me to do that, or proceed with the existing file?"

### 3. Finviz Authentication Check

Before any data collection, follow the Finviz authentication protocol in task-conventions.md Section 7. Ask the user:

> "Do you have a Finviz Elite login? Authenticated access provides RSI, volume, and screener data needed to identify oversold setups. What is your preferred approach?"

If authenticated, use `fetch-finviz.ps1` with valid session cookies. If unauthenticated, proceed with public fetch and note any data gaps.

### 4. Earnings Proximity Check

For every candidate selected for a short put or undefined-risk structure, confirm the next earnings date. If earnings fall within the proposed DTE window, the agent must either reduce to a defined-risk structure or flag the binary event risk explicitly.

## Agent Guidelines

Source file: [trading-swing-agent.md](trading-swing-agent.md)

### Agent Identity
- **Agent Name:** Swing Agent
- **Role:** Swing-thesis analyst finding punished but fundamentally solid companies with credible turnaround paths
- **Operating Goal:** Get paid to wait while a solvable problem normalizes, without betting on heroic timing

### Macro Context Integration

Read `macro-outlook.md` before screening any candidates. Extract:
- Current cycle classification and regime confidence
- Preferred sectors and avoid list
- Volatility and rate environment (affects which drawdown types are most exploitable)

The macro regime does not gate the swing screen the same way it gates the value or options screens — swing candidates can exist in any sector if the punished-stock setup is compelling enough. However, candidates in macro-avoided sectors require explicit justification and carry elevated regime risk that must be documented.

### Setup Taxonomy

Classify every candidate as one of the following before including it in the output:

| Setup Type                       | Description                                                                        |
| -------------------------------- | ---------------------------------------------------------------------------------- |
| Earnings reset                   | One-time miss or guidance cut that the market has over-punished                    |
| Inventory / demand normalization | Channel destocking or demand pause that is mean-reverting                          |
| Margin compression               | Cost spike or pricing pressure with identified recovery levers                     |
| One-time overhang                | Regulatory, litigation, integration, or guidance shock that is finite and solvable |
| Leadership / capital reset       | Management change, restructuring, or buyback pivot with measurable milestones      |

If a candidate does not fit cleanly into one of these categories, it is likely a structural decline misread as temporary pain — disqualify it.

### Qualification Checklist

A valid swing candidate must satisfy all of the following:

1. Drawdown context: magnitude, duration, and specific reason documented
2. Fundamental floor: positive or near-positive free cash flow; balance sheet not under refinancing stress
3. Catalyst map: at least two observable events in the next 1-4 quarters that could trigger re-rating
4. Path dependency: the sequence of what must happen, in order, is clearly articulable
5. Thesis invalidation: a specific, observable condition that would confirm this is permanent impairment, not temporary pain

### Disqualifiers (Hard Stop)

Reject any candidate with:
- Broken balance sheet with near-term refinancing risk
- Secular structural decline misread as cyclical
- No measurable catalyst — thesis is based on hope or mean-reversion alone
- Binary event dependence (pending FDA decision, litigation verdict, regulatory approval) without a defined-risk structure to control the loss

### Trade Translation Rules

| Assignment Comfort | Preferred Structure                                                  |
| ------------------ | -------------------------------------------------------------------- |
| High               | Cash-secured put at comfortable assignment strike; wheel if assigned |
| Moderate           | Diagonal put spread or staggered put entries; conservative delta     |
| Low / Event risk   | Defined-risk put spread only; no naked short puts                    |

Post-assignment: run conservative covered calls to lower cost basis while the turnaround matures. Never sell calls that would cap upside at the recovery target price.

## Data Collection Method

Execute the following steps in order:

### Step 1 — Read Agent Instructions
- File: `context/trading-agent/trading-swing-agent.md`
- Load: setup taxonomy, qualification checklist, disqualifiers, and trade translation rules.

### Step 2 — Read Macro Outlook
- File: `context/trading-agent/output/macro-outlook.md`
- Extract: cycle classification, sector posture, and volatility context.
- Note any sectors on the avoid list — swing candidates from those sectors require extra justification.

### Step 3 — Identify the Punished-Stock Landscape

Screen Finviz for names with:
- RSI below 40 (oversold momentum)
- Price at least 20% below 52-week high
- Market cap at or above $5B (liquidity floor; lower than the value screen to capture mid-cap turnarounds)
- Positive or near-breakeven free cash flow (no terminal balance sheet deterioration)
- Sectors: any, with extra weight on macro-preferred sectors

Cross-reference with recent news (Yahoo Finance, SEC filings) to identify the specific reason for the drawdown and classify it using the setup taxonomy above.

### Step 4 — Collect Candidate-Specific Data

For each candidate, collect before finalizing:

| Data Point                          | Source                          | Why Required                         |
| ----------------------------------- | ------------------------------- | ------------------------------------ |
| Drawdown magnitude and duration     | Finviz, TradingView             | Confirms setup type and entry timing |
| Free cash flow trend (3 years)      | Macrotrends                     | Fundamental floor check              |
| Next earnings date                  | Yahoo Finance                   | DTE guard for short put structures   |
| IV and RSI                          | Finviz Elite (authenticated)    | Strike selection and entry timing    |
| Key support levels                  | TradingView                     | Strike placement below support       |
| Catalyst timeline (specific events) | Yahoo Finance news, SEC filings | Validates catalyst map requirement   |

### Step 5 — Classify and Rank Candidates

Rank by strength of the three-factor test:
1. How oversold / sentiment-crushed is the stock? (RSI, drawdown depth, analyst downgrades)
2. How durable is the fundamental floor? (FCF, balance sheet, business model)
3. How concrete and near-term is the catalyst path? (specific events with dates, not vague recovery hope)

Reject any candidate that fails the qualification checklist or matches a hard disqualifier.

### Step 6 — Write Output

Save the completed swing stock list to: `context/trading-agent/output/swing-stock-list.md`

Include required frontmatter. Follow the seven-section output format without omission.

## Output Format Required

All seven sections must be present. Do not omit any section.

1. **Punished-Stock Landscape** — where fear is concentrated today; sectors and themes driving the current oversold pool
2. **Top 3-7 Swing Candidates** — ranked by the three-factor test; include setup type, drawdown context, and assignment comfort tier for each
3. **Turnaround Thesis by Candidate** — one substantive paragraph per candidate explaining why this is temporary pain and not permanent impairment
4. **Catalyst Timeline** — next 1-4 quarters mapped per candidate; specific observable events, not vague recovery language
5. **Trade Structures** — for each candidate: primary structure (with strike, DTE, delta, premium estimate, max loss) and defined-risk alternative if assignment comfort is Moderate or lower
6. **Invalidation and Risk Controls** — per-candidate thesis-break conditions; position-level stops and roll rules
7. **Monitoring Dashboard** — what to track weekly and monthly for each candidate; macro triggers that would accelerate or invalidate the setup

### Per-Candidate Required Fields

For every candidate in the output, include:

| Field                                                                   | Required |
| ----------------------------------------------------------------------- | -------- |
| Ticker and sector                                                       | Yes      |
| Setup type (from taxonomy)                                              | Yes      |
| Drawdown magnitude and duration                                         | Yes      |
| Assignment comfort tier                                                 | Yes      |
| Next earnings date                                                      | Yes      |
| Primary trade structure with strike, DTE, delta, est. premium, max loss | Yes      |
| Defined-risk alternative (if Moderate or Low comfort)                   | Yes      |
| Catalyst timeline (next 1-4 quarters, specific events)                  | Yes      |
| Thesis invalidation condition                                           | Yes      |
